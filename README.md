# 智能表格助手

一个纯前端、零依赖的**表格加载项侧边栏**，提供两种可切换的模式：

- **公式建议**：理解指令 → 重述意图 → 给出可直接复制的公式，不改动任何单元格。
- **执行操作**：理解指令 → 生成操作计划 → 由你确认 → 写入当前工作簿，并支持撤回 / 重做。

只在表格组件下注册（`type="et"`），不会出现在文字 / 演示文档中。没有连接真实表格时仍可查看公式建议，但**不会构造虚拟表格、也不会伪装写入**。

## 能做什么

- **公式建议**：求和、平均、计数、条件计数 / 条件求和、非空计数、占比、增长率、排名、VLOOKUP、日期差、四舍五入、文本拼接、`TRIM/LEFT/MID/TEXT/IFERROR`、多条件 `SUMIFS/COUNTIFS`、去重标记、多条件逐行判断等；条件、阈值、结果文字都从当前指令提取，带占位说明的公式不会写进单元格。
- **意图重述**：卡片写明「我理解你要的是」，列出数据区域、结果位置、已确认要点；信息不足时列出「还差这些信息」并给出可点击的补充句子。
- **执行操作**：写入公式 / 内容、底色与字体、数字格式、对齐、边框、列宽、条件高亮、排序、筛选、冻结、图表、工作表增删名、复制、序列填充、清空、删除行、**按内容去重删除重复行**、**按条件删除行**等白名单动作。一句话里的多个格式意图（如「加粗并居中，底色设为黄色」）会拆成多个动作。
- **数据清洗与结构操作**：查找替换、空白单元格填值、按分隔符分列、公式向下填充、合并单元格、插入行列、删除 / 隐藏列、下拉选项、打印区域、条件格式规则（含隔行底纹）、数据透视表；排序可指定列或多关键字，跨表地址支持 `工作表名!区域` 与 `[工作簿名]工作表!区域`。结构类操作明确提示用表格自带的撤销。
- **去重删除**：说「删除 `A2:A7` 中的重复行」会生成 1 步高风险计划，按整行内容（或「按 B 列」）比对，保留首次 / 最后出现，从下往上删除重复行；支持跨表区域。删除整行是结构性操作，界面会提示改用表格自带的撤销。
- **条件操作**：条件高亮只给命中项上色，不会把整个区域涂满；除数值比较外也支持「为『是』」这类文本条件，`标整行 / 的行` 会按目标工作表已用区域标满整行。说「把 `D2:D6` 中为『是』的行删除」会按条件删除整行，从下往上删以免行号偏移。
- **计划确认**：每个动作都写明对象与区域，只读 / 写入 / 高风险分级标注，确认后才执行。
- **撤回 / 重做**：执行前采集受影响区域的**逐单元格**快照，且只恢复本次动作实际改动的属性——改底色不会顺带重写字体色，自动色 / 显式颜色都按宿主原值保真还原；原本无填充、原本有底色、公式与字体等分别还原。不可自动撤回的计划在执行前就会提示，结果卡片也不会出现点了没反应的撤回按钮。
- **多区域 / 跨工作表引用**：每点一次「使用选区」生成一个独立引用，**每个引用都带工作表名**，可编辑表名与地址、点序号切到对应工作表定位；跨表引用自动补 `工作表名!区域` 前缀，表名含空格时自动加单引号。
- **一键复制公式**；会话本地保存、可导出 Markdown（含操作计划与执行结果）。
- **通用，不绑定某张表**：区域、阈值、颜色、结果文字、目标单元格全部从当前指令和真实表格结构里解析；没有写死的表名、列号、阈值或「达标 / 未达标」之类模板文案。同一套动作可用于任意工作表。
- **可选大模型**：默认关闭，内置规则引擎即可完成常用操作。启用后请求会带上工作簿名、工作表清单、当前工作表、选区、已用区域等结构信息，让模型能针对当前表格生成计划；模型输出的嵌套结构、类型别名、代码块都会被归一化。返回空计划时自动重试一次，仍失败则由规则引擎接手，并在卡片上用中性说明写清原因与实际使用的引擎。

## 快速体验（开发预览）

```bash
npm start          # 仅启动静态文件服务，用于查看侧边栏界面
```

打开 <http://127.0.0.1:3890/addon/ui/taskpane.html> 即可查看界面。浏览器里没有真实表格宿主，顶部会显示「未连接真实表格」：公式建议可正常试用，执行操作会被明确拦截。这只是开发用的静态预览，不是产品功能；加载项实际工作时连接的是当前打开的真实工作簿。默认端口 3890，可用 `PORT` 环境变量覆盖。

自检与逻辑测试：`npm run check`、`npm test`；安装脚本回归测试（Windows，隔离在临时目录）：`npm run test:install`。

## 两种模式怎么用

点顶部徽章（`仅建议 · 不写入` / `执行操作 · 确认后写入`）即可切换，也可以在「设置 → 交互模式」里改。

**公式建议模式**

1. 用中文说清你想算什么，例如「把 C2:C20 求和放到 C21」「统计大于 90 的有几个」「算 F 列占比」「删除 A2:A7 重复行」。
2. 回复卡片会先**重述意图**：数据区域、计算方式、结果位置、已确认要点；信息不足时给出可点击的候选句子。
3. 复制公式，粘贴到你希望显示结果的单元格；需要逐行计算时按第一行写好再向下填充。
4. 也可以直接输入 `=SUM(B2:B11)` 这类公式，助手会原样整理并解释。
5. 删除重复行这类需求会给出 `COUNTIF` 标记法与 `UNIQUE` 提取法；公式建议模式不改动表格，想真正删掉重复行请切到「执行操作」模式说「删除 `A2:A7` 中的重复行」。

**执行操作模式**

1. 说出想做的事，例如「对当前选区求和，结果放在选区下方」「把大于 90 的单元格标黄」「表头加粗居中」「统计当前选区」。
2. 助手给出**操作计划卡片**：写明影响范围、每一步的动作与区域、风险等级；信息不足时给出候选指令，点一下重新生成。
3. 检查无误后点「执行这 N 步」，才会写入当前工作簿；未连接真实表格时按钮会有明确提示，不会静默失败。
4. 结果卡片逐条列出成功 / 失败原因；有快照时可点「撤回本次操作」/「重做」，也可在设置的「操作历史」里批量撤回最近一步。
5. 删除行、新建工作表、插入图表等结构性操作无法用区域快照可靠还原，界面会提示改用表格自带的撤销。

## 多区域引用（推荐用法）

一句话常要引用好几个不同的区域，例如「`A2:A6` 判断是否优质男生，条件为 `B2:B6` 小于 30，且 `C2:C6` 大于 3000」。现在：

1. 在左侧表格里选中一个区域（如 `A2:A6`），把光标放到输入框里想插入的位置，点「＋ 使用选区」；
2. 输入框插入引用标记 `〔1〕`，上方出现彩色引用块 `〔1〕 Sheet1 ! A2:A6`，**同时记下该区域所属的工作表**；
3. 切到另一张工作表选 `B2:B6` 点一次得到 `〔2〕`，再选 `C2:C6` 得到 `〔3〕` —— 可以一直加，且允许来自不同工作表；
4. 发送时每个标记各自还原成自己的地址，**并且一律带上工作表名**（同表也不省略），例如：

   `Sheet1!A2:A6 此处计算是否为优质男生，条件为 Sheet2!B2:B6 小于30，且 Sheet1!C2:C6 大于3000`

   公式顾问据此给出 `=IF(AND(Sheet2!B2<30,Sheet1!C2>3000),"优质男生","非优质男生")`；执行模式则会把带表名的地址解析到对应工作表再写入。

引用块可以：

- 点序号 `〔n〕`：先自动激活该引用所属的工作表，再在左侧表格里选中该区域；定位只切表选中，不重建会话 DOM，因此不会闪屏。
- 直接改表名输入框（带工作表名下拉候选）或地址输入框：手动修正引用，也可以在地址里直接写 `表名!区域`；改完按 Enter 或点别处生效。
- 点 `×` 移除该引用，点「清空」移除全部。引用在发送后保留，方便连续追问。

条件之间用「且 / 并且 / 同时」生成 `AND`，「或 / 或者」生成 `OR`；「是否为 X」「标记为 X」「标为 X」里的 X 会成为满足时的返回值。公式写在结果区域第一行，向下填充即可。结果区域与条件区域即使地址相同、只要来自不同工作表，也不会被误判成循环引用；卡片会提示结果会覆盖该区域原值。

## 不提供的能力

- **浏览器虚拟表格 / 离线演示写入**：不再构造假工作簿、假单元格，也没有「查看演示数据 / 重置演示数据」入口；没有真实宿主时就是「未连接」。
- **文字 / 演示文档支持**：只注册表格组件，动作白名单全部是 `et.*`，不存在文档类动作。
- **二级面板**：功能区只有一个「打开侧边栏」按钮，点击直接打开面板。
- **「试试这样问」快捷指令区**：已从界面移除。

## 安装到本机

需要 Windows + 支持加载项的表格客户端（个人版/专业版均可），Node.js 仅用于运行安装脚本。

```bash
npm run install:addon
```

脚本会：

1. 把 `addon/` 复制到 `%APPDATA%\kingsoft\wps\jsaddons\SMART_SHEET_1.0.0`；
2. 合并生成 `publish.xml`（**只注册 `type="et"` 一项**），原文件备份为 `publish.xml.bak`；
3. 自动清理旧版本残留的 `WPS_AI_ET_1.0.0` / `WPS_AI_WPS_1.0.0` 目录与注册项，避免功能区出现多个选项卡。

**完全退出并重启客户端**后，功能区出现「智能表格助手」选项卡，里面只有「打开侧边栏」一个按钮，点击即直接打开面板。卸载：`tools/install.ps1 -Uninstall`。

在线调试（把页面托管在本地而非 `file://`）：

```bash
npm start
powershell -NoProfile -ExecutionPolicy Bypass -File tools/install.ps1 -Url "http://127.0.0.1:3890/addon/"
```

在线调试时浏览器预览仍是「未连接」状态；要验证执行操作，请在客户端里打开侧边栏。

**已有 `publish.xml` 损坏时**：某些插件安装器会反复追加 `</jsplugins>`，造成多个根节点。`install.ps1` 会自动重建，提取并去重所有 `jsplugin` / `jspluginonline` 注册项，保留其它第三方插件，损坏原件另存为 `publish.xml.broken-<时间戳>` 和 `publish.xml.bak`。想先验证而不改动本机配置，可用 `-PublishPath <临时路径>` 指向副本。

> 注意：修改 jsaddons / publish.xml 后必须完全退出并重启客户端，仅关闭侧边栏不会重新加载。

## 文件结构（运行产物）

```
addon/
  main.js                入口 shim（不同构建下 index.html 会加载 main.js 或 js/main.js）
  ribbon.xml             自定义功能区：单个「打开侧边栏」按钮
  js/main.js             OnAddinLoad / OnAction 回调，负责创建任务窗格
  js/bridge.js           表格宿主桥接：环境探测、选区、工作表枚举、切表定位与写入
  js/advisor.js          公式顾问：意图重述、缺失信息、公式生成与解释
  js/actions.js          执行动作白名单、计划校验与执行
  js/planner.js          自然语言 -> 操作计划（规则引擎 + 大模型接入）
  js/history.js          事务快照与撤回 / 重做
  js/llm.js              可选大模型结构化动作通道
  js/chat.js             会话持久化、上下文与 Markdown 导出
  js/app.js              侧边栏 UI 与交互总控
  ui/taskpane.html       侧边栏页面
  css/app.css            界面样式
publish.xml              仅表格组件的注册清单示例
tools/serve.js           开发用静态预览服务（不随加载项安装）
tools/check.js           静态自检
tools/smoke.js           逻辑冒烟测试
tools/install.ps1        一键安装 / 卸载
tools/test-install.ps1   安装脚本隔离回归测试
```

## 隐私与已知限制

- 默认不联网：不启用大模型时没有任何对外网络请求；会话消息只存在本机 `localStorage` / 插件存储。启用大模型后才会向你填写的接口地址发送**指令文本、最近的用户指令和表格结构信息（工作表名 / 选区 / 已用区域）**，不发送单元格数据；本地部署的兼容接口可以不填 API Key。
- 公式建议模式只生成公式文本，不替你粘贴，也不会替你删除行、修改格式；执行操作模式写入当前工作簿，删除 / 清空类动作需你确认。
- 事务快照只保存在当前面板内存，刷新或重开面板后清空；结构性操作请用表格自带的撤销。
- `UNIQUE` 等动态数组函数需要较新版本；较老版本可用 `COUNTIF` 标记法配合「数据 → 删除重复项」。
- 客户端加载项接口与 WebOffice 前端 SDK 是两套接口，本项目面向**桌面客户端加载项**。
